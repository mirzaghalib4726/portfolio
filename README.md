# Mirza Usama Ali Baig — Portfolio

Personal portfolio for **Mirza Usama Ali Baig**, Senior Full-Stack Engineer (NestJS · Next.js / React · Nuxt · AI Integrations).

Built with React 19, TypeScript, Vite, Tailwind CSS v4 and Framer Motion. Light/dark themes, tabbed pages (Home, About, Skills, Experience, Projects, Contact) with shareable `#hash` URLs, project case-study modals and a mailto-based contact form — no backend required.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Editing content

All text lives in [`src/data/profile.ts`](src/data/profile.ts) — profile, stats, skills, experience, projects, education and certifications. The downloadable CV is `public/Mirza-Usama-Ali-Baig-CV.pdf`.

## Deploy

Import the repository on [Vercel](https://vercel.com/new) (framework preset: **Vite**). No environment variables are needed.
